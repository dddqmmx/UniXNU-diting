# Diting iOS 27.2.1（24B156）适配交接文档（2026-11-20）

## 1. 当前总体状态

- **目标**：为 Redmi K50 Ultra（`diting`，SM8475，8 核，4 KiB 页）适配 iOS 27.2.1（`24B156`，`iPhone18,2`/`V54AP`，`arm64e` `MH_FILESET`）直至进入用户态。
- **分区与持久化边界**：**未写入任何设备分区**，保留现有 `boot_b`（`services198`）及现有 `Data` 分区。所有实机测试仅通过 `fastboot boot` 临时从 RAM 启动。设备 `1d4eb066` 最后一次 `boot-diag-05` 停留在 XNU 早期启动阶段，需手动长按电源键+音量下回 Fastboot。
- **已验证实机里程碑（`boot-diag-05`）**：
  - `DarwinBoot.efi`（28,160 B / 27,648 B 带 RAM 替换补丁）已在内存中成功替换 `services182/template/diting-unixnu-uefi.img` 固件自带旧 loader；
  - 已完成 `kernel.diag.macho` + `kernel.macho.adt` 校验、`AllocateWindow`（`PA = 0x0000000840004000`、`ENTRY = 0x0000000843dde488`、`TRAMP = 0x0000000845950000`）、`ExitBootServices`（`EXIT RETURN = 0`）；
  - `Entry.S` 跳板在 `0x845950000` 成功执行并画出顶部**青色条**（进入跳板）与第二段**绿色条**（清 cache、关 MMU/TLB 后即将 `br x1` 进入 XNU `start_first_cpu`）；
  - 进入 XNU 内核后在 `serial_init()` / `PE_create_console()` 之前静默卡住（未出现 panic 文字，已知 `debug.c:1261` 在 `PE_kputc == NULL` 时会直接调用 `panic_spin_forever()`）。
